# Setup

The profile is a table of three columns: a tilted order ticket on the left, the receipt in the middle, a tilted stats slip and Telegram ticket on the right. Everything is a local SVG in `assets/`, with no external image services.

The SVGs are generated by `tools/build.mjs` so the character grid and dotted leaders stay exact. The output is plain SVG, so it can also be edited by hand.

## Edit texts, colors, numbers

1. Open `tools/build.mjs`. Everything editable is in the `CONFIG` block at the top:
   - `C` – colors (`paper`, `ink`, `mute`, `red`, `edge`) and `SHADOW_OPACITY`
   - `HEADER` – studio name, city, date, time, receipt number, cashier
   - `PROJECTS` – row name and status
   - `STACK`, `SERVICES`, `TOTALS` – the lists and total lines
   - `ORDER` – the left "HOW I WORK" slip: title, the four steps with one-line descriptions, footer line
   - `STATS` – the right slip: title, the number rows (`PROJECTS 4`, `BOTS 1`, `YEARS CODING 1`, `COFFEE ∞`) and the "OPEN FOR ORDERS" line
   - `TG` – label and handle on the small Telegram ticket
2. Run `node tools/build.mjs` (Node 18+). It rewrites `assets/*.svg` and `tools/preview.html`.
3. Keep text UPPERCASE. A main-receipt row must stay under 44 characters (name + status). Slip description lines wrap automatically at 26 characters.

Colors can also be changed by hand with find-and-replace in `assets/*.svg`:
`#F4F1EA` paper, `#111111` ink, `#6B6B6B` secondary, `#E5322D` red, `#D6D0C0` paper edge.

## Edit the signature, barcode, QR

- Signature: the `SIGNATURE` path in `tools/build.mjs` (plain SVG path data).
- Barcode and QR are drawn from seed text: change `'EDGEWAYY'` / `'KRIEWOO'` in the `footer` and `slip-telegram` blocks to get a different pattern.

## Add or remove a project

Add an entry to `PROJECTS` in `tools/build.mjs`, rebuild, then copy one `<a>...</a><br>` row line in `README.md` and change the file names and link.

## Why the receipt column is wrapped in `<sub><div>`

GitHub gives every inline image a 24px line box. When the page is narrow the scaled images get shorter than that and white gaps open between the stacked segments. `<sub>` has `line-height: 0` on GitHub, and the `<div>` inside inherits it, so the segments touch. Keep that wrapper when you edit `README.md`.

## Preview

Open `tools/preview.html` in a browser. It uses the README markup with GitHub-like table styling.
Add `?bg=dark` or `?bg=light`, `?w=888` (container width) or `?w=358` (phone), `?dbg=1` to print cell widths and row gaps (gaps must be `0.00`).

## Notes

- Animations are SMIL inside the SVGs: header print-in, stamp pop, blinking cursor and red dot. They play on page load, so the stamp may finish before it scrolls into view.
- The repo must be named exactly `EdgeWayy` and be public for the README to show on the profile.
