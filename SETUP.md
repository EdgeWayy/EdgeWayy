# Setup

The receipt is a stack of SVG segments in `assets/`, all 480px wide, joined in `README.md`.
The SVGs are generated by `tools/build.mjs` so the character grid and dotted leaders stay exact. The output is plain SVG, so it can also be edited by hand.

## Edit texts, colors, rows

1. Open `tools/build.mjs`. Everything editable is in the `CONFIG` block at the top:
   - `C` – colors (`paper`, `ink`, `mute`, `red`, `edge`)
   - `HEADER` – studio name, city, date, time, receipt number, cashier
   - `PROJECTS` – row name and status
   - `STACK`, `SERVICES`, `TOTALS` – the lists and total lines
2. Run `node tools/build.mjs` (Node 18+). It rewrites `assets/*.svg`.
3. Keep text UPPERCASE and a row under 47 characters (name + status + 2 spaces), or it will not fit.

Colors can also be changed by hand with find-and-replace in `assets/*.svg`:
`#F4F1EA` paper, `#111111` ink, `#6B6B6B` secondary, `#E5322D` red, `#D6D0C0` paper edge.
For the stats cards, change `bg_color`, `title_color`, `text_color`, `icon_color`, `border_color` in the two URLs in `README.md` (no `#`).

## Add or remove a project

Add an entry to `PROJECTS` in `tools/build.mjs`, rebuild, then add one line to `README.md`:

```html
<a href="URL"><img src="assets/row-NAME.svg" width="480" alt="..." align="top"></a><br>
```

Keep `width="480"`, `align="top"` and the `<br>`. They stop gaps between segments.

## Preview

Open `tools/preview.html` in a browser. It stacks the segments like the README and prints widths and gaps in the corner (gaps must all be `0.00`). Add `?bg=dark` for a dark background or `?w=360` for a phone width.

## Notes

- SVG animations (header print, stamp pop, blinking cursor) run on page load. The stamp sits low on the page, so it may finish before it scrolls into view.
- Stats cards use the public `github-readme-stats.vercel.app` instance, which is sometimes rate limited. Self-host it if cards fail to load.
- The repo must be named exactly `EdgeWayy` and be public for the README to show on the profile.
